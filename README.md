# CINARO — سينارو

تطبيق عربي للأفلام والمسلسلات بواجهة سينمائية مخصصة للهاتف. يعمل كتطبيق ويب تقدّمي قابل للتثبيت (PWA)، ويأتي معه مشروع Android يبني ملف APK تلقائيًا عبر GitHub Actions.

> كل قصة تبدأ هنا

## أهم المزايا

- واجهة RTL متجاوبة للهاتف والتابلت والكمبيوتر.
- شاشة بداية وهوية وأيقونة CINARO أصلية.
- رئيسية ديناميكية: تابع المشاهدة، الأكثر مشاهدة، الجديد، الأعلى تقييمًا والمسلسلات.
- صفحات مستقلة للأفلام والمسلسلات مع التصنيف والترتيب.
- بحث مباشر بالعربية والإنجليزية والتصنيف.
- مفضلة وسجل مشاهدة محفوظان على الجهاز.
- حفظ تقدم مستقل لكل فيلم ولكل حلقة، مع استئناف من آخر ثانية.
- روابط عميقة حقيقية للتفاصيل والتشغيل باستخدام Hash Routing.
- مشغل مخصص: تقديم/تأخير، سرعة، مصادر جودة، ترجمة VTT، ملء الشاشة، صورة داخل صورة والحلقة التالية.
- معالجة أخطاء الفيديو والصور وحالات الاتصال.
- Service Worker لتخزين واجهة التطبيق والعمل دون اتصال.
- مشروع Android WebView آمن يحمل نسخة الويب محليًا ولا يعتمد على بقاء GitHub Pages متاحًا لفتح الواجهة.

## تشغيل نسخة الويب محليًا

يلزم Node.js 20 أو أحدث:

```bash
npm test
npm run dev
```

ثم افتح:

```text
http://127.0.0.1:4173
```

## إضافة فيلم

افتح `web/data.js` وأضف عنصرًا داخل `items`:

```js
{
  id: "movie-unique-id",
  kind: "movie",
  title: "اسم الفيلم",
  englishTitle: "Movie Name",
  year: 2026,
  rating: 8.5,
  ageRating: "+13",
  genres: ["أكشن"],
  duration: 110,
  views: 0,
  addedAt: "2026-09-13",
  description: "وصف الفيلم",
  poster: "https://example.com/poster.jpg",
  backdrop: "https://example.com/backdrop.jpg",
  sources: [
    { label: "1080p", url: "https://example.com/movie-1080.mp4", type: "video/mp4" },
    { label: "720p", url: "https://example.com/movie-720.mp4", type: "video/mp4" }
  ],
  subtitles: [
    { label: "العربية", srclang: "ar", src: "assets/subtitles/movie-ar.vtt" }
  ]
}
```

يجب أن يكون رابط الفيديو مباشرًا عبر HTTPS، وأن يسمح الخادم بطلبات النطاق `Range Requests` حتى يعمل التقديم والاستئناف بصورة سليمة.

## بناء APK

عند رفع أي تعديل إلى فرع `main` يعمل مسار **Build Android APK** تلقائيًا:

1. افتح تبويب **Actions** في المستودع.
2. افتح آخر تشغيل باسم **Build Android APK**.
3. من **Artifacts** نزّل `CINARO-Android-APK`.
4. فك الضغط وثبّت `CINARO.apk` على الهاتف.

الـAPK التلقائي نسخة Debug موقعة من Android وقابلة للتثبيت والاختبار. للنشر في Google Play يجب إنشاء مفتاح توقيع Release خاص وعدم رفعه علنًا إلى المستودع.

## GitHub Pages

المسار **Deploy CINARO PWA** ينشر محتويات مجلد `web` تلقائيًا. بعد أول تشغيل ناجح ستكون النسخة عادةً على:

```text
https://3c5-o.github.io/CINARO/
```

## هيكل المشروع

```text
CINARO/
├── web/                    # تطبيق PWA
├── android-app/            # مشروع Android الأصلي
├── assets/                 # دليل الهوية وبرومبتات الأصول
├── scripts/                # فحص وتشغيل محلي
└── .github/workflows/      # النشر وبناء APK والاختبارات
```

## تنبيه المحتوى

استخدم فقط فيديوهات وصورًا تملك حقوق نشرها أو لديك ترخيص لاستخدامها. المحتوى الموجود في البيانات الحالية تجريبي لتوضيح الربط والتشغيل.
